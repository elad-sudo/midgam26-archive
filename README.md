# MIDGAM26 archive

Static archive of the final results of the MIDGAM26 civic poll for the
elections to the 26th Knesset (27.10.2026), served at https://midgam26.com.

Aggregates only: per-list totals, seats, and the integrity fingerprint
(audit-chain head hash and the SHA-256 of the full anonymous ballot file).
No ballot rows and no identifiers are in this repository.

Pages: `/` (Hebrew), `/ar/` (Arabic), `/ru/` (Russian). Generated by
`scripts/archive-build.mjs` in the private source repository.
